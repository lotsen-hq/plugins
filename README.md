# lotsen-hq plugins

The Claude Code plugin marketplace of [Lotsen](https://github.com/lotsen-hq/lotsen), which gives you a guided tour of a pull request, written by Claude, in a local web UI.

This repository holds only the marketplace file, [`.claude-plugin/marketplace.json`](.claude-plugin/marketplace.json). Its entry points at the `plugin/` folder of the Lotsen repository, at the tag of the latest release.

Install the plugin, inside Claude Code:

```text
/plugin marketplace add lotsen-hq/plugins
/plugin install lotsen@lotsen-hq
```

For what Lotsen does, its requirements, the docs and where to report a problem, see the [Lotsen repository](https://github.com/lotsen-hq/lotsen).
